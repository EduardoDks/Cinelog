O CineLog é uma aplicação web full stack para gerenciamento e organização de backlog pessoal de filmes, séries e animes. Integrado à API do TMDB (The Movie Database), o sistema permite buscar produções em tempo real, consultar sinopses detalhadas, categorizar mídias por status de consumo, atribuir avaliações e registrar análises pessoais em uma interface moderna em Dark Mode.

## 📸 Interface do Projeto

### **Dashboard & Gerenciamento de Backlog**
Visualização em cards com filtros por status (Assistido, Quero Assistir) e categorias (Filmes, Séries, Animes), exibições de notas e tags personalizadas.

### **Modal de Detalhes, Avaliação e Resenha**
Ao selecionar uma mídia, é exibida a sinopse completa integrada via TMDB, permitindo definir o status, atribuir uma nota de 1.0 a 5.0 e escrever um comentário/análise pessoal.
